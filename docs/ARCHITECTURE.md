# Architecture

## Backend (`backend/app`)
```
core/        config (env-only secrets) · security (Argon2id, JWT, refresh digests) · deps (authn + object-level authz)
             middleware (security headers, request id, body cap) · rate_limit · audit · utils
db/          Motor client, indexes (TTL for sessions), mongomock in-memory fallback for dev/test
ai_engine/   motion.py (biomarkers) · baseline.py (robust baseline + risk fusion) · synthetic.py (test data)
ai/          llm (Gemini client) · guardrails · triage · assistant (Medo) · analysts (lab PDF, video, coach, clinician summary)
services/    medication_engine (safety-screened OTC KB) · pdf_report (ReportLab) · storage (magic-byte uploads) · insights
routers/     auth · patients · doctors · analysis · video · assistant · medications · reports (+timeline) · chat · wellbeing (fitness, notifications, SOS)
seed.py      demo data generated by running synthetic pose sequences through the real engine
```

### Key API surface
| Area | Endpoints |
|---|---|
| Auth | `POST /api/auth/{patient,doctor}/register`, `/login`, `/refresh`, `/logout`, `/logout-all`, `GET /me`, `/sessions`, `POST /change-password` |
| Patient | `GET/PATCH /api/patients/me`, `/dashboard`, `/trends`, `/appointments`, `/me/export`, `POST /me/delete` |
| Doctor | `/api/doctors/profile`, `/directory`, `/appointments[/{id}/accept|reject|cancel]`, `/patients`, `/patients/{id}/overview|summary|discharge` |
| Movement | `POST /api/analysis/sessions`, `GET /sessions[?patient_id]`, `/sessions/{id}`, `/summary` |
| Video AI | `/api/video/access`, `/unlock/{pid}`, `/lock/{pid}`, `POST /analyze`, `/history`, `/{id}/review`, `/{id}/pdf` |
| Assistant | `POST /api/assistant/message`, `GET/DELETE /conversations[/{id}]` |
| Meds | `/api/medications/plan` (GET/POST/DELETE), `/log`, `/guidance` |
| Reports | `POST /api/reports/analyze`, `GET /api/reports[/{id}]`, `GET /api/timeline` |
| Chat | `/api/chat/threads`, `/{otherId}/messages`, `/{otherId}/media`, `/media/{messageId}` |
| Wellbeing | `/api/fitness/records`, `/fitness/coach`, `/api/notifications[/read]`, `POST /api/sos` |

Interactive docs: `http://localhost:8000/docs` (disabled in production).

## Frontend (`frontend/src`)
```
lib/api.js           axios client: in-memory access token, single-flight silent refresh, typed endpoint map
store/auth.js        zustand session store (never persisted)
components/ui         design-system primitives (Button, Card, Dialog, Segmented, Field, Data, motion…)
components/layout    AppShell: sidebar, ⌘K command palette, notifications, user menu, mobile tab bar
components/charts    MotorTrendChart, MovementResult
features/pose        usePoseCapture — MediaPipe Pose Landmarker (WASM served locally) + skeleton overlay
features/landing     3D hero (R3F walking skeleton + glass shield), guardrail pipeline demo
pages/public|patient|doctor|shared
```

Design language: "warm clinical" light theme — porcelain canvas, Medo teal with apricot / lilac / butter accents,
Bricolage Grotesque display + Instrument Serif italic accents + Geist body; spring-based motion, tilt cards,
scroll-drawn timelines, Lenis smooth scroll on the landing page.
